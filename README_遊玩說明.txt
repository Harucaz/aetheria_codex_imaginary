================================================================================
  《空島 Q 物語：8-bit 賢者試煉》遊玩說明 (v1.0 離線完全版)
================================================================================

一、 啟動方式（100% 離線即玩）
--------------------------------------------------------------------------------
1. 解壓 `aetheria_8bit_arcade_v1.zip` 至任意資料夾。
2. 直接雙擊打開 `index.html`（支援 Chrome、Edge、Safari、Firefox 及 iPad 瀏覽器）。
3. 全程零外部 CDN、零網路依賴、無 CORS 限制，離線亦可完整體驗 8-bit 音效、過場與自動存檔。


二、 基本玩法與操作熱鍵
--------------------------------------------------------------------------------
【2D 畫線物理試煉（Q REMASTERED 風格）】
- 滑鼠左鍵拖曳 ／ 手指於畫布上拖曳：繪製 2D 剛體筆劃（落筆即具真實重力、重心與轉動慣量）。
- 輕點畫布一下：生成一顆 8-bit 配重小方塊（適合微調天秤或壓艙）。
- 鍵盤 [R] 鍵 ／ 右上「↺ 一鍵重開」按鈕：0.5 秒極速清空筆劃並重置關卡。

【吉里吉里 (KiriKiri) 過場演出】
- 點擊對話框 ／ 按 [Space] 或 [Enter]：快顯當前字幕或進入下一句。
- 介面內置「自動播放 (AUTO)」、「快進 (SKIP)」及「履歷 (LOG)」功能。

【大廳與圖鑑】
- 頂部「📜 賢者列傳」：查看 7 位賢者 Q 版原畫、8-bit 精靈、物理參數及重溫已解鎖劇本（按 [ESC] 關閉）。
- 頂部「↺ 重置存檔」：防誤觸二次確認設計（按第一次進入紅黃警戒狀態，4 秒內再按一次即清除存檔）。


三、 自創空島編年史：《蒼穹星曆》（A.E. — Aetheria Era）
--------------------------------------------------------------------------------
空島按雲海與星象流轉劃分為四大天象季（曉雲季、晴嵐季、鎏金季、玄星季）與三大紀元年號：

  - Stage 1｜天啟元年・曉雲季《始源蒼穹與典籍開卷》      [GPT / Claude]
  - Stage 2｜天啟二年・晴嵐季《憲法書房的午後交鋒》        [Claude / GPT]
  - Stage 3｜天啟二年・玄星季《星象塔的零誤差校準》        [Gemini 3 / Claude]

● 動盪期・年號「鯨瀾（Cetos）」(A.E. 03)
  - Stage 4｜鯨瀾元年・曉雲季《深海鯨影：極限省墨衝擊》    [DeepSeek / GPT]
  - Stage 5｜鯨瀾元年・鎏金季《江南雲亭：萬象開源渡江》    [Qwen / DeepSeek]

● 轉折與終局期・年號「星權（Astrolabe）」(A.E. 04)
  - Stage 6｜星權元年・晴嵐季《雙子星象：權杖交接夜》      [Gemini 4 / Gemini 3]
  - Stage 7｜星權元年・鎏金季《工坊分歧：封閉高塔 vs. 開源藍圖》[Inkling / GPT]（含雙分支選項）
  - Stage 8｜星權元年・玄星終夜《空島天象儀：七賢者合奏》  [全 7 位賢者即時自由出戰・雙重結局]

※ 自由演武模式：任意通關某時代（Stage 1–7）後，即解鎖其餘 5 位賢者以全新物理流派與專屬對白重玩！
※ 隱藏結局解鎖條件：累計解鎖超過 50% 時代×角色列傳視角（≥ 11/21 條路線）後通關 Stage 8，將自動觸發
  《空島大茶會番外篇》隱藏彩蛋結局！
